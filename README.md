# GEO Lite（开发中）

问 AI → 看信源 → 写稿 → 发布 → 回查 的最短闭环工具，本地运行，数据和 Key 只存在自己电脑上。

## 启动

```bash
cd ~/代码库/GEO-Lite
node server.js          # 默认 http://localhost:3000，数据在 ./geo-data/
```

需要 Node 20 以上，不用装任何依赖。

## 进度

| 步骤 | 状态 |
|---|---|
| 1 接入 AI 平台 | 千问（百炼）、豆包、DeepSeek（都走火山方舟，需开通联网内容插件）已接通；元宝未接（需腾讯云 Key，未验证） |
| 2 建项目 | 可用：品牌、别名、品类词、官网、竞品、正确联系方式 → 15 个问题 |
| 3 跑数 | 可用：每问 N 次，并发 3，失败自动重试，配置类错误（欠费/未开通）不重试 |
| 4 诊断 | 可用：要不要做两盏灯、分端提及率+误差、竞品、分端信源表、被引用最多的文章、错误电话、AI 实际推荐的名字 |
| 5 写稿 | 可用：按诊断出待办建议 → 品牌资料 → 母稿 → 子稿（示范提示词可改，不联网写） |
| 6 发布 | 可用：手动发，贴链接，第 3 天去百度搜标题登记收录。一键推草稿箱下一版 |
| 7 回查 | 可用：选基线/回查两轮对比提及率、联系方式、错误电话；按链接认出每篇稿有没有被引用 |
| 跑数续跑 | 服务重启后没跑完的轮次自动接着跑；可手动停止 |
